무엇이든 물어보세요. 출처가 명확한 답변을 Apple Intelligence가 여러분의 기기에서 직접 생성해 드려요. 기본적으로 프라이빗해요. 추적 없음. 광고 없음. 구독 없음.

여러분이 사용하는 모든 검색엔진은 검색 기록을 추적해요. AI 챗봇은 여러분의 질문을 확인할 수 없는 서버로 보내죠. 더 나은 방법이 있어요.

AISight는 웹을 비공개로 검색한 뒤, Apple Intelligence가 결과를 읽고 명확한 답변을 작성해요. iPhone, iPad, Mac 어디서든 가능하고, 기본적으로 AI 처리를 위해 데이터가 기기 밖으로 나가지 않아요.

● 출처가 있는 AI 답변
자연어로 질문하세요. AISight가 여러 출처를 검색하고 읽은 뒤, 번호가 매겨진 인용과 함께 간결한 답변을 작성해요. 인용을 탭하면 원본을 바로 확인할 수 있어요.

● 프라이빗 AI, 선택은 여러분 몫
기본은 온디바이스예요. Apple Intelligence가 기기에서 바로 답변하고, 어떤 AI 서비스로도 데이터를 보내지 않아요. iOS 27과 macOS 27에서는 AISight Pro로 Apple Private Cloud Compute를 사용해 더 강력한 모델을 쓸 수 있고, Apple의 프라이버시 설계로 보호돼요. 또는 OpenAI, Mistral, Claude, Ollama, OpenAI 호환 서비스 등 직접 사용하는 AI 제공업체를 무료로 연결할 수 있어요.

● 여러분의 언어로 답변
한국어, 영어, 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 일본어, 중국어로 질문하면 AISight가 질문과 같은 언어로 검색하고 답변해요.

● 완벽한 프라이빗 검색
계정 불필요. 추적 없음. 광고 없음. 데이터 판매나 공유 없음. 검색 결과는 여러분을 프로파일링하지 않는 오픈소스 프라이빗 메타검색엔진에서 가져와요.

● Deep Search
표면적인 결과를 넘어서세요. Deep Search는 여러 번의 AI 리서치로 복잡한 질문에 더 나은 답변을 찾아줘요.

● 검색 기록은 내 기기에만
모든 검색 기록과 답변이 기기에 안전하게 저장돼요. 검색하고, 다시 보고, 관리하세요. 어떤 서버에도 동기화되지 않아요.

● 나만의 서버 연결 — 무제한, 무료
자신의 SearXNG 인스턴스를 연결하면 무제한 검색과 Deep Search가 자동으로 잠금 해제돼요. 구매할 필요 없어요. 저는 여러분의 데이터를 원하지 않아요. 데이터를 직접 운영하는 서버에 두면 저에게 아무것도 낼 필요가 없다는 게 그 증거예요.

이렇게 작동해요
1. 질문을 입력해요
2. AISight가 여러 검색엔진을 통해 비공개로 웹을 검색해요
3. AI가 결과를 읽고 종합해요. 기본적으로 기기에서 처리해요
4. 출처를 확인할 수 있는 답변을 받아요

이럴 때 딱이에요: 흔적 없이 조사하고 싶을 때, 공부하면서 출처 있는 답변이 필요할 때, 리타겟팅 광고 없이 제품을 비교할 때, 아니면 그냥 검색이 원래 이래야 한다고 생각할 때.

심플하고 정직한 가격
무료: 제 서버에서 하루 10회 검색 가능. 완전한 AI 답변과 인용 제공. 직접 사용하는 AI 제공업체도 무료로 연결할 수 있어요.
Pro (일회성 구매): 무제한 검색 + Deep Search + Apple Private Cloud Compute (iOS 27 및 macOS 27). 인디 개발자를 응원해 주세요. 구독 없음.
셀프 호스팅: 나만의 서버 연결 → 무제한 검색과 Deep Search 영원히 무료.

인디 개발자가 만들었어요. 벤처캐피탈 없음. 데이터 수익화 없음. 외부 SDK, 분석 도구, 트래커 제로. 여러분의 프라이버시를 존중하는 네이티브 앱이에요.

AISight — 더 스마트하게 검색하고, 프라이버시를 지키세요.
